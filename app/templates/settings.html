Media paths

Jellyfin reports every file's path from inside its own container (e.g. /Filmer/Movie/movie.mkv). Add a row per library so JFTools can open the real file: the Jellyfin path on the left, and the path on this machine on the right.

If the paths already match — e.g. the container mounts the same folders Jellyfin uses — you don't need any rows; leave this empty. Otherwise click Fill with library paths, adjust the right-hand path where it differs, then Save.

File management

Subtitle preferences

Used by Smart mark in the Internal dialog and as the default language list for OpenSubtitles searches.

Comma-separated codes or names (e.g. en,sv or English,Swedish). Empty means English. Smart mark leaves tracks with an unknown language unmarked.

OpenSubtitles

Used by the Search/Movie Match Subtitles action to find and download missing subtitles from opensubtitles.com. Downloads are saved next to the video and require File management (above) to be on. Search languages come from Subtitle preferences above.

Backup

Download everything — settings, media-scan results, Movie Match data, schedules and caches — as one ZIP, or restore a previous archive.

The archive contains your Jellyfin API key, login hash and OpenSubtitles login, so keep it private. Player cache is excluded. Restoring requires a restart.
